- **回调 ref 在渲染期赋值会被 `react-hooks/refs` 拦住**:`onSelectRef.current = onSelect` 写在函数体里 ESLint 直接报 error。解决:放进 `useEffect(() => { onSelectRef.current = onSelect }, [onSelect])`;这个 ref 的存在本身是为了让加载 effect 不把 `onSelect`（每次渲染都是新函数）吃进依赖。
